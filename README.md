# HR Analytics Dashboard 

An interactive Power BI dashboard focusing on active headcount distribution, performance indicators, and key workforce trends. This dashboard provides granular insights into the structure and flow of the workforce across different managers, departments, and tenure bands

---

## 🚀 Key KPI Indicators

This dashboard tracks critical point-in-time and movement metrics:

* **Active Headcount (Active HC):** 944 current employees
* **Overall Headcount:** 1K total employees including departures
* **Attrition:** 346 voluntary/involuntary exits
* **Attrition %:** 0.26 (or 26%)
* **Transfer:** 52 internal role movements

## 📊 Detailed Visual Insights

### 1. Leadership and Organizational Structure
* **Active HC by Reporting Manager:** A funnel-chart style visualization showing manager span of control. Top 3 managers are Ryan Simmons (308), Janelle Wiley (171), and Roberta Moyer (153).
* **Active HC by Job Level:** A donut chart illustrating the hierarchy split: Professional (37%), Trainees (29%), Management (21%), and Contract (13%).

  * 1+ Years: 245

## 🎛️ Interactive Data Drill-down

This dashboard includes advanced filtering capabilities on the right-hand panel:

* **Dynamic Dropdown Slicers:** For `JoinYear`, `Gender`, `Department`, and `EmploymentType.
* **Direct Search Input Box:** For `Employee ID` and `Full Name`, allowing for immediate search of specific records.

---

## 🛠️ Technical Implementation

* **BI Tool:** Microsoft Power BI Desktop
* **Calculations:** DAX for KPIs, percentage distributions, and trend analysis
* **Design:** Custom-branded icons for KPI tiles and advanced chart types (fan chart, sunburst donut)
* **Filters:** Both multi-select drop-downs and input text searches for granular exploration
